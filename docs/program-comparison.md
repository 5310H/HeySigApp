# Optional saved-program comparison

Open Noise → Compare saved programs. Choose two existing daytime programs and
explicitly review a return program. Start comparison sends nothing. Try A,
Try B and Return each send one manual program request through the existing
validated executor. Each request stops Automatic and applies that program's
existing saved levels; fitting, saved targets and role assignments are unchanged.
Therapy programs are excluded. A changed fitting invalidates the comparison.

Use the same speaker and background for both programs. Confirm the hearing-aid
announcements yourself: successful app playback does not acknowledge reception.
Judge words understood, listening effort, comfort and environmental awareness
separately, including worse outcomes. Stop if uncomfortable. This is an optional
manual check, not calibration, a clinical assessment or a requirement for Automatic.

Return is a manual button near the top. Leaving or closing does not send a return
command. Return before leaving when desired. The app cannot read the aids' current
program or restore externally changed levels it never knew.

Feedback consists of four categorical choices in Activity memory only. It is
cleared on leaving/clearing the comparison or Activity destruction; it is not
written to preferences, audio, transcripts, analytics or network storage. It does
not train the model, alter thresholds or change Automatic. No microphone capture,
new permission, background service or dependency is added by this screen.
