# Gradle and API 36 migration — October 16, 2026

## Build structure

Pinned Gradle 8.13, Android Gradle plugin 8.13.2, Kotlin 2.2.10 and JDK 17.
Both apps compile with SDK 36; phone targets 36/minimum 29, Wear targets
35/minimum 30. Shared logic runs as a JVM module with JUnit wrappers around
the existing regression checks. [Build/reproduction guide](../gradle-release-builds.md).

Debug apps keep `com.heysig.batteryprototype` and `com.heysig.watchdev` with
their original development certificates. Compared old/new APK signer digests,
verified signatures, then installed with `adb install -r`; no uninstall or
settings reset was used. Keys were copied to ignored `private/signing/` so
Gradle clean cannot remove them.

Production candidates share `com.heysig.app` and the local upload signer, with
phone version code 1,000,009 and Wear 2,000,003. Development receiver/transport,
research Activity and test runners are separated from production sources.
The Wear production candidate is not a functional companion: normal pairing
remains unimplemented and submission is blocked.

The first Chromebook run failed: `Back did not return to Home`. The explicit
`enableOnBackInvokedCallback=true` manifest opt-in fixed the repeat test.
Both final runs reported `windowFocusBeforeBack=true`. No microphone capture,
hearing-aid commands or changes to remembered aid settings were part of the
runner. The helper checks instrumentation result text because ADB itself can
exit zero on a runner failure.

No device running exactly Android 16 was available. Android 17 exercises the
API 36-targeted paths on a newer runtime; exact Android 16 coverage remains a
separate pre-submission matrix item. These checks do not certify microphone,
speech recognition, audio playback or physical hearing-aid reception.

## Checks and corrections

- Shared Gradle tests: three regression wrappers passed with zero failures or
  errors (manual/voice cases, relative noise measurements and six-level Observe).
- APK certificate comparison verified preservation of both development signers.
- Initial release lint caught a missing permission guard at the microphone
  capture entry point; added a direct runtime check. Permission revocation is
  still caught by the bounded worker's exception path.
- The legacy framework Back override retains a targeted GestureBackNavigation
  lint exception for pre-33 compatibility. API 33+ uses the registered platform
  dispatcher, verified by the device checks above.
- The first long combined build hit a compiler failure after a metaspace
  warning; the configured heap/metaspace limits were increased for subsequent
  builds. No source check was disabled to address the memory issue.

  `:wearApp:assembleDebug` and `releaseCandidates` completed successfully.
- Phone and Wear release lint passed with zero errors. Remaining warnings:
  13 phone / 5 Wear, covering application icons, resource/localization,

Play readiness still requires the remaining
