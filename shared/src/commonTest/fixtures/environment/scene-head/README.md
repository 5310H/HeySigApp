# Experimental six-scene head

Automatic aid dispatch remains disabled. This is a development classifier, not qualified six-scene recognition. The dated [acceptance report](../../../../../../docs/acceptance/environment-scene-head-2026-10-31.md) records the actual guarded decisions and limitations.

`corpus.json` freezes 28 licensed public references before fitting, including source hashes, creator/participant-separated partitions, credits, transformations and provisional scene references. Twenty-six sources are long enough for a three-second sample. Two are excluded, never padded or looped. AMI headset mixes are not far-field scenes. Source audio is downloaded only by explicit developer commands and is not included in application APKs. No user recordings or transcripts were used for training.

Use a separate Python environment with NumPy, ai-edge-litert, scikit-learn, threadpoolctl, ffmpeg and the LiteRT FlatBuffer schema. Recorded fitting versions: Python 3.11.2, NumPy 2.4.4, ai-edge-litert 1.4.0, scikit-learn 1.9.1. Android continues to use its existing pinned LiteRT runtime. Run from the repository root:

```sh
python tools/environment/fetch-scene-corpus.py --cache /tmp/heysig-environment-corpus
python tools/environment/derive-scene-encoder.py --output /tmp/scene-encoder.tflite
python tools/environment/scene-features.py --cache /tmp/heysig-environment-corpus --model /tmp/scene-encoder.tflite --output /tmp/scene-features.npz
python tools/environment/fit-scene-head.py --features /tmp/scene-features.npz --output /tmp/scene-head.bin
python tools/environment/export-scene-evidence.py --features /tmp/scene-features.npz --output /tmp/scene-evidence.bin
bash tools/report-scene-head.sh /tmp/scene-encoder.tflite /tmp/scene-head.bin shared/src/commonTest/fixtures/environment/scene-head/corpus.json /tmp/scene-evidence.bin /tmp/scene-evidence.tsv /tmp/scene-report.tsv
python3 tools/test-scene-corpus.py
```

Downloads must match every pinned hash. Mirrors may change or become unavailable; failures never authorize silently replacing bytes, references or partitions. Fetching honors bounded downloads and HTTP errors. FSD50K-derived WAVs pin the mirror's decoded Opus bytes, not original source WAVs. AMI reads only the pinned 30-second excerpt, seconds 120–150, using verified HTTP ranges.

The encoder exposes the existing 1024-byte quantized embedding beside the original 521 event scores. Shared Kotlin pools mean and population standard deviation, then L2-normalizes 2048 values. Waveform gain is bounded (target RMS .05, max 16x, peak .95); this is not SPL calibration. Class-balanced source-group weighting and leave-source-group-out development log loss select regularization and temperature. Validation sources do not fit coefficients or tune these parameters.

`scene-head.bin` uses magic `HSGENV1\n`, encoder SHA-256 (32 bytes), three little-endian int32 values (1024, 6, pooling version 1), then float32 temperature, minimum centroid cosine and minimum probability margin. For each of six fixed classes it stores a float32 bias, 2048 float32 weights and 2048 float32 centroid coordinates. Shared Kotlin strictly validates the format, dimensions and values. Runtime hashes pin both artifacts. Scene logits/softmax are not clinically calibrated probabilities. Novelty, ambiguity, music and speech contradictions abstain. There is no legacy fallback after an uncertain head result.

`device/scene-fixtures` contains six short development-source PCM regressions with per-file hashes and license/transform notices. These are instrumentation-test assets only, not held-out accuracy or physical microphone evidence. They are never played. APK/AAB validators reject them in main applications. Instrumentation checks the full native encoder/shared head against independent scalar reference scores. Model notices and CC BY text ship separately with both applications.

To regenerate the six test-only development excerpts from the exact scalar reports:

```sh
python tools/environment/make-scene-regressions.py --cache /tmp/heysig-environment-corpus --fit-report docs/acceptance/data/environment-scene-head-fit-2026-10-31.json --decision-report docs/acceptance/data/environment-scene-head-2026-10-31.tsv --output /tmp/scene-fixtures
```

The CC BY license text and AMI attribution in the existing fixture directory must accompany redistribution. Fixture manifest bytes are pinned by instrumentation; review/re-pin intentionally if model or references change.

Fitting is numerically reproducible, not promised bit-for-bit across solver runs/platforms. A same-input refit selected the same C/temperature and all 274 guarded decisions; 12 of 24,582 stored floats differed by at most 2.98e-8. The shipped head is independently hash-pinned, not regenerated by Gradle. Review new binary hashes, scalar decisions and native regressions before intentionally replacing it. Encoder derivation and test-PCM regeneration matched their existing pins exactly.

## Expanded-source experiment and held-source-out diagnostics

`expanded-corpus.json` preserves every original source/partition and adds seven sources. The two `freshValidationIds` were unused before the November 1 experiment; they are now viewed evidence and cannot be called unseen in subsequent tuning. See the [rejection report](../../../../../../docs/acceptance/environment-scene-expansion-2026-11-01.md). New CC BY 3.0 entries require creator credit, source/license links and transformation notes. Noncommercial/unreviewed licenses remain rejected. No expanded model is shipped.

Use the same feature/export commands above with `--manifest shared/src/commonTest/fixtures/environment/scene-head/expanded-corpus.json`. Give outputs distinct paths. Add `--cv-output /tmp/new-scene-cv` when fitting to create a new directory of source-excluded development heads. Each fold excludes its group from both coefficients and centroids. After compiling the reporter with `tools/report-scene-head.sh`, run:

```sh
python3 tools/environment/report-scene-cv.py --manifest shared/src/commonTest/fixtures/environment/scene-head/expanded-corpus.json --encoder /tmp/scene-encoder.tflite --cv-directory /tmp/new-scene-cv --evidence /tmp/expanded-evidence.bin --references /tmp/expanded-evidence.tsv --jar shared/build/scene-head-report.jar --output /tmp/development-cv.tsv
python3 tools/environment/summarize-scene-report.py --manifest shared/src/commonTest/fixtures/environment/scene-head/expanded-corpus.json --report /tmp/development-cv.tsv --output /tmp/development-cv.json
python3 tools/test-scene-reports.py
```

`--cv-output` must name a new directory. These folds share development-selected hyperparameters and are not nested independent validation. Their 78 correct/30 wrong/104 abstentions contradict the fitted-source 159/0/53 result. Neither those numbers nor extra public references qualify real automatic commands. Candidate/fold weights remain developer-cache artifacts, not production assets. The actual phone/watch scene head and its hash remain unchanged.
